VOID GARDEN — an original arcade game in plain HTML/CSS/JavaScript with no dependencies. You are a wisp of light in a dark circular garden. Gather glowing motes to score and feed the clock, build combos up to ×5, and dash through the thorn sentinels that hunt you to shatter them for bonus points — touch one without dashing and you lose a heart. Reach 1,200 points before the 75-second clock runs out to make the garden Bloom. Title, pause, win and lose screens, escalating waves, particle effects and synthesized WebAudio sound effects included. Move with WASD/arrows, dash with SPACE or a click, pause with P.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 — or just open `game/index.html` in a desktop browser; it runs fully offline. `node main.ts` is the hand-in program: it copies `game/` and `screenshots/` to the output directory and writes `dossier.json`.
